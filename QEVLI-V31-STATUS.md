# Qevli V31 status

V31 adds the distributed-platform foundation while preserving all V1–V30 features.

## Enabled in code
- Redis cache abstraction
- BullMQ queue abstraction
- Worker process
- Redis Stream event bus
- S3/R2 storage abstraction
- CDN URL abstraction
- Presigned media upload endpoint
- PostgreSQL outbox/background-job tables
- Region configuration
- Scale health/config endpoint

## Still needs real provider setup
- Upstash Redis database
- Cloudflare R2 bucket/API credentials
- Cloudflare custom CDN domain
- Production worker deployment
- Monitoring/alerting provider
- Real multi-region PostgreSQL topology

## Monetization

Subscriptions and advertising remain disabled server-side.
