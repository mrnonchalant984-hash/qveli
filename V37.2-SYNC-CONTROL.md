# Qevli V37.2 — Admin Sync Control

V37.2 adds visible official-feed synchronization controls to the admin panel.

## Admin controls
- **Sync all now** runs all enabled official sources immediately.
- **Sync** on an individual enabled source runs only that source.
- Last sync and last successful sync timestamps are shown.
- Last source errors remain visible.
- Manual admin sync works even when `QEVLI_CRON_SECRET` is configured.
- Scheduled cron authentication still uses `QEVLI_CRON_SECRET` when configured.

## Local development
No R2 or payment card is required. Local media storage remains the default.

## After replacing the project
```powershell
npm install
npx prisma generate
npx prisma migrate deploy
npm run seed:official-sources
npm run dev
```
