# Qevli V37.2 — Admin Sync Now

V37.2 adds a visible **Sync all now** control to `/admin`.

- Admins can manually trigger official-feed synchronization from the dashboard.
- Each source shows last sync, last successful sync, item count, and last error. Each enabled source also has its own **Sync** button; the top **Sync all now** button syncs every enabled source.
- Disabled sources are not synchronized.
- Vercel cron remains responsible for automatic production synchronization.
- No R2, S3, or payment card is required. Local media storage remains the default.

## Local test

```powershell
npm install
npx prisma generate
npx prisma migrate deploy
npm run dev
```

Open `/admin`, scroll to **Automatic feed sources**, and click **Sync all now**.
